# Codex-Skin v0.7.1

本版本修复 v0.7.0 在当前 Codex 桌面端只应用基础颜色、但未显示主题背景和首页布局的问题。

- CDP 兼容性探测与主题渲染器现在共用同一个主内容区选择器，同时支持旧版 `main-surface` 和当前 `MainContentSurface` 结构。
- 只有主内容区确实完成主题装饰时才将注入判定为成功，避免“应用成功”但背景、首页文案和快捷卡片未生效。
- 恢复 Pupu Ivory Alley 等带背景主题在当前 Codex 首页的完整视觉效果。
- 将 Crystal Clear 与 Twilight Lake 素材从客户端仓库迁回 Codex-Skin-Store 草稿区；完成真实预览、素材许可和双平台审核前不会进入公开目录。

## English

Fixes a v0.7.0 regression where current Codex desktop builds received theme colors but not the background or themed home layout. Runtime detection and rendering now share one main-surface selector, and injection succeeds only after that surface is actually decorated. Crystal Clear and Twilight Lake assets have also moved to the Store draft area pending real screenshots, licensing review, and cross-platform validation.
