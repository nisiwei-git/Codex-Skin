# Codex-Skin v0.7.0

本版本适配当前 Codex 桌面端页面结构，提升主题应用与客户端更新的可靠性，并加入玻璃主题能力。

- 识别当前 Codex 主内容区和编辑器结构，避免新版桌面端无法应用主题。
- 仅向 Codex 主窗口注入主题，跳过头像浮层等辅助页面。
- 主题应用在主窗口初始化期间自动重试，并针对“窗口未就绪”和“页面结构不受支持”给出更准确的提示。
- 新增 `glass` 视觉强度和透明窗口背景支持，并加入 Crystal Clear 与 Twilight Lake 主题草稿。
- macOS 客户端更新按钮直接进入下载与安装流程，避免重复确认导致操作失效。

## English

Adds support for the current Codex desktop page structure and a new glass visual mode. Theme injection now targets only the main Codex window, retries while it initializes, and reports clearer compatibility errors. The release also includes transparent-window theme support, Crystal Clear and Twilight Lake theme drafts, and a more reliable macOS update action.
